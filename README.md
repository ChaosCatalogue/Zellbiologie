# Zellbiologie

## Zellmodell im Browser

Die öffentliche Grafik ist unter
<https://chaoscatalogue.github.io/Zellbiologie/> erreichbar. Der Workflow
`Deploy cell model to GitHub Pages` veröffentlicht bei jedem Push auf `main`
automatisch `Zellmodell-Code.txt` als `index.html` und kann zusätzlich manuell
gestartet werden. Diese Datei ist die einzige Quelle für die gehostete Grafik;
neue Modellfunktionen müssen dort ergänzt werden.
`Zellmodell-Grafik.html` ist eine separate Kopie und nicht die Quelle der
gehosteten Seite. Das Repository ist öffentlich, daher ist auch sein Quellcode
öffentlich einsehbar.
